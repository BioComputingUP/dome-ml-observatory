About DOME Observatory

A searchable database of AI/ML methods-paper metadata, mapping the AI/ML landscape in the life sciences at scale.

Records are drawn from Europe PMC, classified by LLM screening against published criteria, and tagged with controlled vocabularies. The classification method itself was validated against a hand-annotated expert benchmark before being run across the corpus.

DOME Observatory is part of the DOME-ML family, alongside the DOME Registry, and is developed by the BioComputing UP lab at the University of Padua.

How the corpus is built

  1. 1

    Method validation

    The classification method was benchmarked against 6,000 publications hand-annotated by an expert curator. Every expert–LLM disagreement was adjudicated, and reconciled agreement exceeded 90% before the bulk run was authorised. What was validated is the method, not each record.

  2. 2

    Screening

    Every publication is classified by an LLM as positive, negative or undeterminable, with a written rationale kept beside the verdict. Each record page carries the model, prompt version and rationale behind its own decision; the processing history shows when each batch ran.

  3. 3

    Enrichment

    A separate pass tags positively-classified records with EDAM domain, learning paradigm, model family and model type, drawn from published controlled vocabularies. This step is still in progress across the corpus — the search page shows live coverage.

Limitations

  • Machine-generated throughout: every classification and enrichment in the corpus is LLM-generated. The method behind them was validated against a hand-annotated expert benchmark before being scaled (see Method validation above), so accuracy is high-confidence at corpus scale — but no individual record has been reviewed by a curator, and any single record's tags are a strong starting point rather than a guarantee.
  • Enrichment coverage is partial: that pass is still running across the corpus, so most records currently show "not yet enriched" rather than a full tag set.
  • Cross-links are not yet populated: the DOME Registry, Hugging Face, Kaggle and Zenodo fields are reserved in the schema but empty for every record — see Integrations for what's live versus planned.
