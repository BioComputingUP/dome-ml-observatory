Every publication is classified as positive (a genuine AI/ML methods paper), negative, or undeterminable, with a written rationale kept alongside the verdict on each record — see how the corpus is built for the full method. Undeterminable records are held for a later pass rather than discarded; that pass may need a different approach than this round used, such as pulling full text where it's available, rather than the abstract alone.
