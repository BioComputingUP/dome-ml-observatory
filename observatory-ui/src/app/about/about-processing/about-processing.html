Processing history

DOME Observatory's corpus is built in discrete processing rounds, not a continuous live feed. Each round is logged here by hand as it completes — source, search space, what was processed, and the classification result — so the provenance behind every number on the site is traceable.

Every publication is classified as positive (a genuine AI/ML methods paper), negative, or undeterminable, with a written rationale kept alongside the verdict on each record — see how the corpus is built for the full method. Undeterminable records are held for a later pass rather than discarded; that pass may need a different approach than these rounds used, such as pulling full text where it's available, rather than the abstract alone.
