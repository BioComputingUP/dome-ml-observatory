About DOME Observatory

DOME Observatory is a searchable database of AI/ML methods-paper metadata: records screened and classified by LLM processing, validated by human expert curation, and cross-linked to Europe PMC. It maps the AI/ML landscape in the life sciences at scale — currently {{ corpus().total | number }} publications screened, {{ corpus().positive | number }} of them classified as genuine AI/ML methods papers.

It is part of the DOME-ML family, alongside the DOME Registry, and is developed by the UNIPD Biocomputing Lab.

How the corpus is built

  1. Screening. Every publication is classified by an LLM as positive (a genuine AI/ML methods paper), negative, or undeterminable, with a written rationale kept alongside the verdict. This decision is machine-generated — see any record page for the model, prompt version and rationale behind a given classification.
  2. Enrichment. A separate pass tags positively-classified records with EDAM domain, learning paradigm, model family and model type, drawn from published controlled vocabularies. This is the more expensive step and is still in progress across the corpus — the search page shows live coverage.
  3. Human validation. Curators review classification and enrichment output against the source criteria, rather than accepting model output uncritically.

Limitations, stated plainly

  • Classification and enrichment are LLM-generated. They are validated, not infallible — treat a record's tags as a strong starting point, not ground truth.
  • Enrichment coverage is partial while that pass is still running across the corpus; most records currently show "not yet enriched" rather than a full tag set.
  • citation_count is reserved in the schema but has never been populated for this corpus — it is not silently zero, it is genuinely absent.
  • Cross-links to the DOME Registry, Hugging Face, Kaggle and Zenodo are reserved fields, not yet populated for any record — see Integrations for what's live versus planned.
