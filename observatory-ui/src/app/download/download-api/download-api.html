API

In development. The API is not live yet — this page documents the planned contract so integrations can be designed against it now. It ships with the observatory-ws backend; a Swagger/ OpenAPI explorer will replace this static reference once it does.

A read-only REST API over the same corpus Search uses. Good for targeted queries and small numbers of records; for the whole corpus, use bulk download instead so requests stay light for everyone.

Fair use

No hard rate limit is set yet, but please don't page through /api/records to reconstruct the full corpus — that's exactly what bulk download exists to avoid, and it's faster for you too.
