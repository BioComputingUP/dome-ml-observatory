Format
JSON Lines, gzipped — one complete record per line, UTF-8, the same records the API's export serves. Streamable: gunzip -c into mongoimport loads it without holding the whole file in memory. Beside it on Zenodo, archive-metadata.json gives the counts and the sha256 of every file, and the schema file the records follow.

Licence
CC BY 4.0 on Observatory's own classification and enrichment layer. The bibliographic metadata and abstracts come largely from Europe PMC and keep their own terms, and each paper's licence governs that paper — see Licensing & citation.
Update cadence
Every two months, as new triaged content is added. Each release is versioned, so an analysis can pin the exact snapshot it used.

Citing the corpus

Please cite the DOME Observatory preprint, which describes the corpus and the methodology behind it, and cite Europe PMC alongside it — see Licensing & citation. The preprint will be posted on arXiv but is still in preparation, so check back here for the full citation before submitting your work. The corpus grows with each update, so also note which release you used, to keep the analysis reproducible.
