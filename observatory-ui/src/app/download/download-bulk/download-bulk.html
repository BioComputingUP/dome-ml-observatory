Update cadence
Monthly to bimonthly, as new triaged content is added. Each release is versioned and citable in its own right, so an analysis can pin the exact snapshot it used.

Citing a release

Cite the specific release you used, not just the site — that's what makes an analysis reproducible, since the corpus grows with each update. A preprint describing the corpus and its methodology is the preferred citation; cite the Zenodo DOI alongside it when you need to pin the exact data snapshot an analysis used.
