Downloading the data

Every record in DOME Observatory is available to take out of the browser — either as one archive covering the whole corpus, or through a read-only API for targeted queries. This page explains the difference so you can pick the right one before you start.

Two ways to access the corpus

Bulk download

For: whole-corpus analysis, local indexing, reproducible snapshots.

  • One JSONL archive, versioned and DOI-citable
  • No rate limit — one request, no paging
  • Best for: bulk analysis, reproducible pipelines
See what a release contains

API

For: targeted queries, a handful of records, live lookups in a tool.

  • Live JSON over HTTPS, current data
  • 300 requests/min, up to 10,000 records
  • Best for: lookups, integrations, small queries
