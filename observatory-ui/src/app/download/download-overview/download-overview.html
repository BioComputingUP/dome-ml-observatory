Getting the data

Every record in DOME Observatory is available to take out of the browser — either as one archive covering the whole corpus, or through a read-only API for targeted queries. This page explains the difference so you can pick the right one before you start.

Two ways to access the corpus

Bulk download

For: whole-corpus analysis, local indexing, reproducible snapshots.

One file, one request, no rate limits, and a DOI you can cite in a paper. This is the recommended way to take the corpus at scale — it's faster for you than paging an API, and it keeps load off the service for everyone else.

See what a release contains →

API

For: targeted queries, a handful of records, live lookups in a tool.

Lighter-weight requests against current data — good for looking up specific records or integrating a search into another tool. Please don't page it to pull the whole corpus; that's what the archive is for.

Also worth knowing: Europe PMC

DOME Observatory's records are cross-linked to Europe PMC — it's the underlying source the corpus is built from (see how the corpus is built). That makes it a viable complementary source in its own right: if you need the full text or metadata of a specific publication rather than its DOME classification and enrichment, or you're looking for coverage beyond what's currently screened here, Europe PMC's own search and API are worth using directly alongside Observatory's bulk archive and API.
