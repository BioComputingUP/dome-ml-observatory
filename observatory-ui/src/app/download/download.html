Bulk download

The whole dataset in one file. This is the recommended way to take the corpus at scale — it's faster for you than paging an API, and it keeps load off the service for everyone else.

The archive is not published yet. Bulk releases will be deposited to Zenodo with a citable DOI. Until the first deposit exists, use Search to explore the corpus, or the API for programmatic access to specific records.

What a release will contain

Format
JSONL — one complete record per line, UTF-8. Streamable, and importable directly with mongoimport without loading the whole file into memory.
Records
{{ corpus().total | number }} screened publications, of which {{ corpus().positive | number }} are classified AI/ML methods papers.
Schema
Version {{ schemaVersion() }}. Every record conforms to the published schema — field definitions, controlled vocabularies and a changelog ship alongside the data.
Licence
CC BY 4.0 — see Licensing & citation.
Update cadence
Monthly to bimonthly, as new triaged content is added. Each release is versioned and citable in its own right, so an analysis can pin the exact snapshot it used.

Which route should you use?

Bulk download

For: whole-corpus analysis, local indexing, reproducible snapshots.

One file, one request, no rate limits, and a DOI you can cite in a paper.

API

For: targeted queries, a handful of records, live lookups in a tool.

Lighter-weight requests against current data. Please don't page it to pull the whole corpus — that's what the archive is for.

Citing a release

Cite the specific Zenodo DOI of the release you used, not just the site — that's what makes an analysis reproducible, since the corpus grows with each update. Citation details will appear here once the first deposit is made.
